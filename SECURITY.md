# Segurança

## Não publique

- senhas e tokens;
- `.env`;
- certificados A1 e suas senhas;
- CSC;
- bancos reais;
- dados pessoais de clientes;
- XMLs fiscais reais;
- logs sensíveis.

## Reporte de vulnerabilidade

Comunique de forma privada ao responsável pelo repositório. Não abra issue pública contendo prova de conceito, credenciais ou dados pessoais.

## Requisitos

- Segredos em variáveis de ambiente ou cofre.
- Tokens criptografados em repouso.
- HTTPS em produção.
- Menor privilégio por perfil.
- Logs de auditoria para ações críticas.
- Dependências atualizadas após testes.
