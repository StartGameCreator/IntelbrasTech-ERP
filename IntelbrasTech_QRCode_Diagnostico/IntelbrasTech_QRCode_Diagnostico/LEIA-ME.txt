DIAGNOSTICO DO QR CODE DA NFC-e

1. Extraia esta pasta.
2. Execute COLETAR_QRCODE_NFCE.cmd.
3. O script NAO altera o projeto.
4. Ele cria um ZIP dentro de D:\Skill\IntelbrasTech-ERP contendo somente os arquivos e dados necessarios para corrigir o QR Code.
5. Envie o ZIP gerado.

O diagnostico verifica:
- URL qrCode existente no XML autorizado;
- urlChave;
- campos XML da ultima NFC-e;
- view do DANFE;
- controller do PDF;
- servicos fiscais;
- pacotes de QR Code/DANFE instalados;
- extensoes PHP necessarias.
