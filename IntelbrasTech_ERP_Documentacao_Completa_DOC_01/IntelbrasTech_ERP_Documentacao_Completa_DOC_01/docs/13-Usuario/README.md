# Manual do usuário

## Acesso

Use as credenciais fornecidas pelo administrador. Nunca compartilhe sua senha ou token.

## Navegação

O menu agrupa as funções por domínio: dashboard, CRM, cadastros, comercial, compras, estoque, financeiro, fiscal, PDV, marketplaces, expedição, logística, OS e configurações.

## Boas práticas

- Confirme empresa e cliente antes de emitir documento fiscal.
- Revise produtos, quantidades e valores antes de concluir vendas.
- Não repita uma operação após erro sem verificar se ela já foi processada.
- Registre observações relevantes em pedidos, OS e devoluções.
- Use os filtros e pesquisas antes de criar cadastros duplicados.

## Procedimentos críticos

Cancelamentos, devoluções, alterações fiscais, exclusão de usuários e reprocessamento de marketplace devem ficar restritos a perfis autorizados.
