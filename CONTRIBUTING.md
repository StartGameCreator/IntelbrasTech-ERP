# Contribuição

Este é um projeto proprietário. Toda contribuição exige autorização do mantenedor.

1. Crie uma branch a partir da base autorizada.
2. Não inclua `.env`, banco, certificados, tokens ou dados reais.
3. Mantenha o escopo da alteração pequeno.
4. Atualize testes e documentação.
5. Execute testes backend e build frontend.
6. Descreva impacto, migrations, rollback e validação no pull request.
