# Ordem de serviço

## Entidades encontradas

- Ordem de serviço
- Status
- Peças

## Fluxo sugerido

Abertura → diagnóstico → orçamento → aprovação → execução → conferência → entrega → encerramento.

Campos obrigatórios e transições de status devem ser validados no backend, e não apenas na interface.
